# Dasha's Birthday Wishlist 🎀

Вишлист ко дню рождения Даши (25 ноября 2026). Гости выбирают подарок, скидываются на него целиком или частично в рублях или рупиях, а Даша подтверждает поступления.

## Как устроено

| Часть | Где |
|---|---|
| Сайт (React + Vite + Tailwind) | `web/`, публикуется на GitHub Pages автоматически при каждом изменении в `main` |
| База, хранилище файлов | Supabase (бесплатный тариф) |
| Схема и логика БД | `supabase/migrations/` |
| Серверные функции | `supabase/functions/` — создание заявки (с капчей), загрузка чека |
| Ежедневный «пинг», чтобы база не засыпала | `.github/workflows/keepalive.yml` |

Деньги хранятся целыми числами в минимальных единицах (копейки, рупии), все проверки сумм и бронь выполняются в базе атомарно с блокировкой подарка. Курс рубль→рупия задаётся вручную и фиксируется в каждой заявке.

## Безопасность

- В репозитории нет секретов: только публичный адрес проекта Supabase и публичный (publishable) ключ — они и так видны в браузере.
- Платёжные реквизиты хранятся в базе и выдаются только после оформления заявки; прямого доступа к таблицам нет (RLS).
- Чеки лежат в приватном хранилище, их видит только администратор.
- Service role ключ, токен Telegram-бота и секрет капчи хранятся только в секретах Supabase.

## Локальный запуск

```bash
cd web
npm install
npm run dev
```

Без файла `.env.local` / `.env.production` сайт работает в режиме предпросмотра на демо-данных.
